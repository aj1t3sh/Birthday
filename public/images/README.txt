=====================================================
📸 HOW TO ADD YOUR SISTER'S (BAUNI'S) PHOTOGRAPH
=====================================================

1. Choose a nice portrait photo of your sister (Komal / Bauni).
2. Rename your photo file to:
   bauni.jpg

3. Place it directly in this folder:
   public/images/bauni.jpg
   (Replace the current placeholder file)

4. Supported formats: .jpg, .jpeg, .png, .webp
   (If using .png or .webp, you can update the filename in src/config/birthdayConfig.js)

That's it! The website will automatically update across all sections with her photo! ✨
